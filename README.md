# 📖 Overview

The **AR Virtual Button System** is an Augmented Reality project developed using **Unity 3D** and **Vuforia Engine** that enables users to interact with virtual objects using marker-based virtual buttons.

The system overlays digital content onto real-world image targets and allows users to trigger actions such as:
- Animations
- Object transformations
- Multimedia interactions
- Scene transitions
- Interactive AR events

This project demonstrates the integration of:
- Augmented Reality
- Computer Vision
- Real-time Interaction Systems
- Marker-based Tracking
- Immersive UI/UX Design

# ⚙️ System Workflow

```text
Camera Detects Image Target
              ↓
Vuforia Tracks Marker
              ↓
Virtual Buttons Activated
              ↓
User Interacts with AR Scene
              ↓
Trigger Animation / Action
              ↓
Real-Time AR Feedback
```

---

# 📸 How It Works

1. The mobile camera scans the predefined image target.
2. Vuforia detects and tracks the marker in real time.
3. Virtual buttons are mapped onto specific regions of the marker.
4. When a user interacts with the button area:
   - Animations are triggered
   - 3D objects respond dynamically
   - Interactive actions are executed
5. The AR environment updates instantly based on user interaction.
